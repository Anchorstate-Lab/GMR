# GMR — Grounded Memory Runtime

> 让主观记录挂靠在客观可重算的观测上，在世界**沿你声明的方向**变化时把它重新交出来。

**状态：重构中。** 架构刚被重新定义（锚定层从无状态的差集改成一台状态机），代码正在跟上。本文只描述已经确定的架构；**接口尚未稳定，暂不建议依赖。**

---

## 问题

你写下一条判断——「这个函数的签名不该变」「这条契约要在服务边界内成立」「这个指标该在季度末越过某条线」。它当时是对的。

半年后它还对吗？没人知道。因为**没有任何东西把这条判断和它依赖的那部分世界连起来**。笔记系统会忠实地把它交还给你，包括它已经错了的时候。

## 做法

```
保证   记录不会沿你声明的方向与世界脱节而无人知晓
不保证 沿未声明的方向。系统不出声
```

这个限定不是免责声明，是这套设计的**第一风险**：你是否声明对了方向，决定这个系统有没有用。GMR 做的是把「记忆悄悄过期」从隐式且无记录，变成内容寻址、可审计、有修订历史的。它没有消除这个问题。

### 什么值得锚

> 锚在**事实约束判断、但不决定判断**的地方。

- 事实完全决定判断 → 不要锚。跑一次就知道，记录是纯冗余
- 事实完全不约束判断 → 锚不住，退化成散文存储
- **事实约束但不决定** → 锚在这里

接口签名约束「密码在服务边界内哈希」这条契约，但不决定它——签名不变，实现照样可以违反。这条缝隙就是判断必须存在的理由，也是这个系统全部价值所在。

## 架构

```
记忆层    主观记录的引用。内容住在外部提供方，GMR 不复制
   │
锚定层    一台状态机 —— GMR 的全部实质
   │
事实层    外部世界。GMR 不存储、不摄入
```

### 锚定层是状态机

```
δ(state, obs, 时间) → state'
```

- `state` 装两样东西：**探针位置** + 域自己的累积量
- `obs` 是插件这次吐的状态向量
- 状态变了 = 一次转换 = 一条边沿

转换条件写成规则表（守卫 → 新状态），第一条匹配即生效。**这就是状态机的转换表本身**：可读、可 diff、可逐条修订。

### 三方分工

| | 给什么 | 形态 |
|---|---|---|
| **基底** | 状态槽 · 转换记账 · 日志 · 密封 · 终结兑现 | 代码 |
| **插件** | 观测 → { 位置, 状态向量 } | 内容寻址的可执行物，版本 = 哈希 |
| **锚** | 在乎哪些方向 · 转换表 · 终结态集合 | 数据，可读可 diff |

**表示归插件，注意力归锚。** 插件吐出全部它能看见的方向；锚声明这个锚在乎哪些。同一个插件因此能服务关注点不同的多个锚。

**没有固定的状态词表。** 一个域的漂移可逆自愈，另一个域的结算不可逆终结——它们没有共同的状态机，基底不替你选。

基底只解释一件事：**这个状态在不在终结集合里**。其余全部被计算、被记录、被通知，不被据以做任何决定。

## 设计约束

- **版本必须挣得来，不能靠声明。** 插件的版本是它的内容哈希——哈希不可能撒谎，手写的版本串可以
- **只增不改由存储层兑现，不靠自觉。** 日志拒绝更新与删除
- **求值路径不碰 IO，由 crate 边界扛。** 不靠 trait 分裂，靠依赖清单——这是机械可查的
- **不可逆由基底兑现。** 靠域在转换条件里自觉守的不变量，等于没有不变量
- **基底不认识值的类型。** 一旦它认识「数值」，就会想认识阈值、趋势、优先级。分档靠多开锚

## 明确不做

| | 为什么 |
|---|---|
| 存储事实层 | 它是外部知识库 |
| 用新规则重算旧观测 | 插件链没有可归档的中间物。**无解法** |
| ship 一份「该检测什么」的清单 | 锚点永远列举不完全，下一个真正有人在乎的方向不会在清单上 |
| 分级 / 严重度 / 告警阈值 | 阈值是判断，归读模型 |
| 判断的可重算 | 不可能。只保证可追责 |
