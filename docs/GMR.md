# GMR 架构

---

## 0. 是什么

> **一个让主观记录挂靠在客观可重算的观测上、并在世界沿作者声明的方向变化时把它重新交出来的运行时。**

```
保证   记录不会沿作者声明的方向与世界脱节而无人知晓
不保证 沿未声明的方向。系统不出声
```

这个限定是设计的**第一风险**,不是免责声明。作者是否声明对了方向,决定这个系统有没有用。记忆在现实中的失效模式恰恰是"沿当初没想到的方向脱节了"。GMR 把这件事从**隐式且无记录**变成**内容寻址、可审计、有修订历史**——这是它的贡献,但它没有消除这个问题。

### 什么值得被锚定

> **锚在事实约束判断、但不决定判断的地方。**
>
> - 事实完全决定判断 → 不要锚。跑一次就知道,记录是纯冗余
> - 事实完全不约束判断 → 锚不住。退化成纯散文存储
> - **事实约束但不决定** → 锚在这里

接口签名约束"密码在服务边界内哈希"这条契约,但不决定它——签名不变,实现照样可以违反。**这条缝隙就是判断必须存在的理由,也是记忆必须存在的理由。**

### 确定性不是客观性

「同插件 + 同目标 ⇒ 同观测」对任何纯函数恒真。它买到的是**确定性**,不是正确性。

基底里没有来源信任分级,但信任没有被消除——它搬到了"谁写的插件、谁选的目标、谁写的转换条件"里。那些地方基底看不见,**不在基底的账上,但仍在系统的账上**。

## 1. 三层

```
记忆层    主观记录的引用。内容住在外部提供方,GMR 不复制
   │ 挂靠(m:n)
锚定层    一台状态机。GMR 的全部实质在这里
   │ 观测
事实层    外部世界。GMR 不存储、不摄入、不维护覆盖率
```

**引用严格单向**:记录 → 锚 → 事实。基底拒绝反向引用。

---

## 2. 锚定层是一台状态机

```
δ(state, obs, 时间) → state'
```

| | |
|---|---|
| `state` | 锚的当前状态。装两样东西:**探针位置** · **域自己的累积量** |
| `obs` | 插件这次吐的状态向量 |
| `state'` | 新状态。与 `state` 不等 = 一次转换 = 一条边沿 |

**state 对基底不透明,但不是黑盒。** 精确含义:基底能寻址它的结构,但不解释任何字段的含义。基底取得出某个字段,不知道那个字段是什么意思——就像它能取出观测里的某个值,却不知道那个值代表签名还是价格。

### 位置住在 state 里

**探针位置是状态的一部分,不是插件的输出。** 域设置探针看哪儿;插件去看;看到的东西回来更新状态,其中就包括"我们现在盯着哪儿"。

这一条塌掉了三套本来分家的机制:**挪参照值**、**换观测位置**、**换派生规则**——它们分家的唯一原因是基底看不见位置。位置进了 state,三者都只是**一次状态转换**。

### 转换表

转换条件写成规则表,不是一个大表达式。**第一条匹配即生效。**

```
守卫条件  →  新状态
守卫条件  →  新状态
终结态集合
```

这就是状态机的转换表本身:可读、可 diff、可逐条修订。改一条 = 一次带密封理由的修订,读的时候看得见改了哪一条。

### 终结由基底兑现

锚上声明哪些状态是终结态。进入终结态后,基底**停止调度,并拒绝此后一切写入**——不只是转换,也包括改状态、改判据、改终结集合本身。

**不可逆是结构,不是判断。** 靠域在转换条件里自觉守的不变量等于没有不变量——一个写错的条件就能让它回去,而日志里看不出这是 bug 还是有意。

**「终结过」是日志里发生过的事,不是对最后一个状态的一次重新解释。** 这两者的差别不是措辞。按后者算,任何把状态挪出终结集合的动作都能静默复活这个锚,于是读的人必须先问「它以前终结过吗、后来谁动过终结集合」才敢用这个答案——终结就不再是一条能依赖的结构事实,只是当下这一次解释。

### 判据写错了:开新的一代,不是拽回旧的

终结不可撤销,所以纠错的出路是**接替**:开一个新的锚,声明它接替哪一个已经终结的锚,理由随之密封。旧的那一代永远是关的。

**代价说清楚:接替不迁移任何东西。** 挂在旧锚上的记录不会自己跟过来,历史也不会合并。换来的是消费方永远不必处理「复活」这一类边沿,而「这个判断当初按什么判据下的」始终指向一份不会被改写的日志。

终结是基底唯一解释的语义。其余全部被计算、被记录、被通知,**不被据以做任何决定**。

## 3. 三方分工

| | 给什么 | 形态 | 版本 |
|---|---|---|---|
| **基底** | 状态槽 · 转换记账 · 调用插件 · 日志 · 密封 · 终结兑现 | 代码 | 求值器版本 |
| **插件** | 位置 → 状态向量 | **内容寻址的可执行物** | **哈希,挣来的** |
| **锚** | 在乎哪些方向 · 转换表 · 终结态集合 | **数据,可读可 diff** | 改它 = 一次带理由的修订 |

**表示归插件,注意力归锚。** 插件吐出全部它能看见的方向;锚声明这个锚在乎哪些、什么条件算转换。同一个插件因此能服务关注点不同的多个锚,不必为每个关注点重编译。

**注意力必须是数据,不能是黑盒。** 改锚上的转换表,读的时候能看见"从什么改成什么",修订带密封理由;改插件,基底只看得见哈希变了,看不见变了什么。而"这个锚在乎什么"恰恰是事后最需要审的东西。

## 4. 三段边界

划清"基底规定死"、"基底提供的语言"、"域完全自由"三段,是这套设计能不能长期不腐坏的关键。

### ① 基底规定死 —— 域没有选择

```
插件的输入          位置。**域给的** —— 它是「去看哪儿」
插件的输出契约      一个可判等的状态向量
插件的失败契约      怎么表达「我没看成」—— 与「我看了,那儿什么都没有」必须可分
转换函数的签名      δ(state, obs, 时间) → state'
求值失败的处置      转换条件炸了 → 不转换 + 发边沿。域无权决定"这次就算了"
终结的兑现          进入终结态后拒绝一切后续写入。域无权反悔
```

第四条不能交给域:**域没法处理"自己的表达式炸了"这件事。** 这是"系统里不允许存在既不成条目、也不发边沿的路径"的落点。

**「去看哪儿」和「实际在哪儿」是两个量,不要混成一个。** 输入侧的位置由域给,基底只从状态里那个槽取值。输出侧探针可以回报它实际的落点——那是观测里一个普通方向,和别的方向没有区别。

禁止后者会把 §5「位置该是模糊坐标」整节掏空:那节的全部价值是「位置没对上、别的对上 ⇒ 搬家了,该把位置挪过去」,而要挪过去,就得有人说出挪到哪。

**基底仍然不解释它。** 落点回来之后是域的事:域写一条转换规则把它写进新状态的位置槽,或者不写。基底自始至终只知道有位置这个槽,以及去哪儿取它。

### ② 基底提供的语言 —— 是规范,不是语义

路径取值 · 比较 · 逻辑 · 算术 · 空值判定 · **对象构造**(转换条件要吐出完整的新状态)。

「哪些方向变了」以**语言算子**的形式提供,不是基底每次替域算好一个差集存进日志。域用它是在用语言,就像用加号——**基底提供算子,不解释值的含义**。

**语言必须保持小**:纯、可终止、无 IO、无时钟、无随机。没有读时钟的能力,否则同一份日志重放两次得到不同结果,整条可重算链当场作废。时间只来自观测字段或日志已记录的时刻。

复杂的判定归**插件**——它可以任意复杂,因为它的版本是哈希锁死的。**能算的搬进插件,只留判定给转换条件。**

### ③ 域完全自由 —— 基底一个字都不说

状态里装什么 · 状态叫什么名字 · 什么条件算转换 · 插件内部怎么实现。

**没有固定的状态词表。** 一个域的"漂移"可逆自愈,另一个域的"结算"不可逆终结——它们没有共同的状态机。基底若定死一套词表,第一个域的语义就进了基底,第二个域只能伪装成第一个的形状。

## 5. 插件

**插件是内容寻址的可执行物,不是进程内的接口实现。**

版本 = 内容哈希。**版本必须挣得来,不能靠声明**——一个内容哈希不可能撒谎,一个手写的版本串可以。这条是整个可追责链的地基:少了它,日志里存着的状态就无法判断是"当时算出来就是这个"还是"后来插件改了逻辑",而这两者的处置完全相反。

调用方式(子进程 · HTTP · 读文件)是**可插的传输**,传输的选择也进哈希:两个传输对同一份声明的解释若不同,那就是两条不同的派生规则。

**代价必须说清:** 想在进程内跑闭包做插件的嵌入方没有可哈希的对象——它要么把插件做成可寻址的东西,要么接受自己不在这条担保之内。这不是做不到,是这条担保的定义如此。

**基底不沙箱插件。** 碰网络碰时钟的插件不是被拦住,是重放时露馅。

### 位置该是模糊坐标

位置是域定义的类型,基底不解释它。但有一条经验要写下来,因为它是从实测里
撞出来的:**位置应该是模糊坐标,不是精确地址。**

精确地址(行号、完整路径、结构序号)在第一次改动后就失效,而代码本来就会
动。模糊坐标(若干项各自可选)配上「报告哪几项对上、哪几项没对上」的匹配,
让同一次观测同时回答三个问题:

```
名字没对上,别的对上   东西还在,改名了
位置没对上,别的对上   搬家了 —— 该把位置挪过去
签名没对上,别的对上   契约变了
全都没对上            真没了,或者变得认不出来
```

**腐坏的类型由「哪几项没对上」直接读出,不需要额外的探针。** 扫全量的探针
做不到这一点:它只知道集合变了,要知道「同一个东西改了名」得算两个数组的
差集,而探针看不到历史、转换表也没有集合运算。

这是**给探针作者的建议,不是基底的规定**。基底仍然只认识「有位置这个槽」。

### 可证伪性完全依赖目标可重取

```
目标内容寻址且不可变   →  成立。重跑必得同一答案,不同即分歧
目标会变              →  不成立。"答案不同"有两个无法区分的解释:
                         插件不纯,或世界变了
```

**不可重取是常态,不是边角情形。** 所以绝大多数情况下,一条观测记录不是一份可复核的推导,是**一台机器在某一刻的封存证词**。它的证据力全部来自:观测原样存在条目里、版本号一并存、日志只增不改、密封不可篡改。这四条都是真的,且都跟目标可不可重取无关。

**基底不标注可证伪性,也不声称它。** 那住在插件的声明里,而声明可以撒谎。跟处理信任同构:搬走了,不是消除了。

### 派生规则升级的爆炸半径

任何一跳的派生规则变了,状态都可能在世界毫无变化的情况下全系统翻转——插件换了输出结构,或求值器换了比较语义,效果完全一样。

这不是能靠数据结构消除的,只能靠**记账 + 预案**:每条条目记下当时的两个版本号(插件的 · 求值器的),消费方据此识别"这批翻转来自规则升级,不是来自世界"。**记了版本却没有这条预案,等于修了记录、没修爆炸。**

两个版本号不许合并:它们是两个独立演进的规则,出错方式不同,合并任何两个都会在其中一边撒谎。

## 6. 记忆层

**GMR 只存引用与绑定时那一版的标识,不复制内容。** 内容住在外部提供方,靠提供方按版本取回。

对提供方的要求:稳定 id · 按 id 取回 · 可判等的版本 · **按版本取回**。最后一条是关键——判断"它还在说同一件事吗"需要知道"从什么改成了什么",只有现在这一版不够。

**绑定说"关于什么",订阅说"什么时候"。**

```
绑定    这条记录是关于这个锚的        关于什么
订阅    我关心哪些转换               什么时候
```

绑定不该承担订阅的职责。把"什么时候才交出这条记忆"塞进绑定,绑定就变成了带条件的订阅,而条件又要问"是数据还是代码",再套一层。信噪比问题的解法在订阅侧。

**记录之间的链接被携带,不被执行。** 一条记录的状态不依赖另一条记录的状态。传播语义在不同场景可以完全相反,不该由基底选。

**同锚共存**(两条记录挂在同一个锚上)是从绑定派生的**查询**,不是存储——它不可能是幻觉,因为它是两份记录各自选择了同一个可观测对象这件事的结构后果。

**接地不沿链接传播。** 无锚记录允许存在,它们靠遍历被捎带,但拿不到任何保证,读取时必须标注。

## 7. 边沿

```
转换      状态变了。变到哪由域的状态说话,订阅方按状态过滤
终结      进入终结态
观测失败  插件跑不起来 · 连续失败 · 陈旧
记录改写  绑定的记录被外部改写了
```

基底不发明"升级""告警""优先级"。它只让"我上次看之后,哪些锚转换到了哪些状态"可以被廉价地问出来。

**记录改写不来自日志**——日志里只有绑定时那一版的标识,内容住在提供方,所以这一类要向提供方问"现在是哪一版"。

**事件驱动部署仍需一个最小心跳来检测停摆。** 没有轮询就没有东西去发现缺席。这是固有代价,不能靠数据结构消除。

---

## 8. 存储

按可变性分。写入频率、一致性要求、崩溃语义没有一条相同,合成一个接口就等于逼实现方给只增不改的日志开后门。

```
日志      只增不改。带写入令牌校验       非有不可
绑定库    只增不改。引用 · 挂靠 · 密封    非有不可
队列      可变。到期 · 租约 · 失败计数    可选:仅轮询部署
```

**只增不改由存储层拒绝更新与删除来兑现,不靠自觉。** 基底 ship 接口,不 ship 后端:核心的依赖清单里不得出现任何数据库。

**租约单独不够,必须配写入令牌。** 租约到期不等于持有者停工——日志必须拒绝过期令牌的写入。没有这一条,"租约担保去重"就是过度声称。

## 9. 物理结构

```
基底      领域无关。不产二进制
电池      可复用,不属于任何单一域:传输实现 · 内容提供方实现 · 存储后端
域        插件 · 锚声明 · 记忆 · 装配与命令行
```

**装配就是域的决定。** 选哪个传输、哪个内容提供方、哪个后端——这三个具体选择一旦写死在基底的产品壳里,那个壳就不再领域无关了,不管它的代码里有没有出现域的词汇。这是最容易被漏掉的一处渗透,因为它看起来像"默认配置"。

**电池这一层存在的理由**:脚本传输和文件内容提供方确实不属于任何单一域(任何域都能用),但也不该被基底强制装配。它们是可选电池,由域来挑。

## 10. 已知代价

诚实列出,不藏。

**1 谁写插件与转换条件(产品存亡级)**
整套接地能力挂在"有人能为这个锚写出正确的插件与转换表"上。**接地的质量上限等于判据作者的水平上限。** 可行路径是提议 + 人确认 + 插件与转换表都内容寻址、可审计、可修订。

**2 用新规则重算旧观测:做不到**
插件链没有可归档的中间物,观测已经是终点。插件升级只能向前生效,历史条目照原样保留、带着当时的版本号。

**3 域要自己数数**
基底不再提供跨观测的派生量(连续计数、上一次的值)。域把需要的累积编码进状态。简单的域因此多写几行,换来的是不会再有基底强加的语义(比如"计数的是观测次数还是时间"这种由基底替你选的口径)。

**4 绑定只有警告,没有拒绝**
锚可以先于它的目标存在,所以引用了不存在的方向只警告。代价是拼错的路径与"目标还没长出来"在开锚那一刻长得一样,都要等运行期才现形。无免费解法。

**5 接地率算不出分母**
被锚的记录数基底数得出,记忆总量住在外部提供方而提供方只有按 id 取回。**基底提供分子,分母由产品补齐;没有产品补分母,这条指标不存在。** 基底能独立看见的是互补的那一头:建了锚却没有任何记录挂上去。

## 11. 文档自我约束

**本文档只写架构决定。禁止写入:具体类型名 / 字段名 / 函数名 / 常量数值 / 文件名 / 调用链。**

那些是代码的唯一真相,写进来就开始腐化——而且腐化的形态很具体:文档描述的接口在代码里不存在,读文档的人(包括下一个 AI)把它当现状,于是照着不存在的东西继续设计。

**也不写验收清单。** 一份自己列的检查表,用它给自己打分,是这个项目已经犯过的错误:每一轮都是"发现洞 → 补那个洞 → 宣布补齐",而分母始终是自己列的。机械可查的约束应该是可执行的检查,不是文档里的条目。

**不写走查例子。** 例子会被下一个人读成清单,而下一个真正有人在乎的方向不会在任何清单上。
