- release v0.3.0
- a read hands back when the snapshot was taken, and whether there is one
- the union rule was written twice and only one copy had the proof
- a fault called Absent is the one word this system spends its life separating
- a derived store may raze itself, not the file it was pointed at by mistake
- delete the path that handed out a file it had already read
- the four probes run one body, and the closure is default-in
- what an extractor is, read out of the four that already exist
- the sort key had one definition and it lived in the tests
- the index on SQLite, and why a derived store is razed rather than migrated
- the index contract, its reference implementation, and the order trap
- the narrowing property had a shape of coordinate it never generated
- sweep the temporaries a killed process could not rename away
- an unreadable cache is a fault to report, not a reason to stop
- cancellation runs down the tree; and two truths about the budget flag
- the budget reaches the work, so cancellation stops being decorative
- cache the per-file half, memoise the fold, stop paying for both
- see Rust constants, and stop the cache from hiding that it now can
- land the postings union, with its equivalence proved before anything uses it
- write the cache once per scan, not once per file
- release v0.2.3 ([#3](https://github.com/Anchorstate-Lab/GMR/pull/3))
- :Cache: scope the scan memo by root, not just probe name
- gmr check: stop re-walking and re-parsing the whole repo per anchor
- release v0.2.1 ([#2](https://github.com/Anchorstate-Lab/GMR/pull/2))
- one declaration of what a coordinate probe emits, and no dead 98%
- one kind of shape, because a hand-written rule is not a kind of shape
- the file walk and the coordinate match, with no language in them
