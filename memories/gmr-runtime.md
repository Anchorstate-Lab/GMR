# gmr-runtime — 装配与动词

模块最多的一个包。它是**唯一同时看得见探针、求值、存储的地方** ——
所以也是最容易把三者的语义黏在一起的地方。

## 公开面变了要问什么

新增的动词有没有替域做判断？基底只解释一件事：终结。其余全部被计算、被记录、被通知，
**不被据以做任何决定**。

一次观测的归宿是固定的五种：已终结 · 三类失败（跑不起来 / 形状不对 / 守卫算不出来）·
看过没动 · 转换。少一种就会出现「既不成条目、也不发边沿」的静默通道。
