# gmr-expr — 求值

JSON + 四个槽（观测 · 状态 · 观测时刻 · 进入当前状态的时刻）→ 值 | 缺失 | 故障。
不认识锚，不依赖 gmr-core。

## 公开面变了要问什么

**语言变大就变危险。** 加一个算子之前先问：这件事能不能搬进探针？
探针的版本是内容哈希，锁死的；语言的语义变了只能靠求值器版本号，而那要人记得改。

纯度（无 IO · 无时钟 · 无随机）由依赖清单扛，`gate.sh` 读 `architecture.toml` 的禁区清单查。
没有 `now()` 是刻意的：时间只来自观测字段或日志已记录的时刻，否则同一份日志重放两次
得到不同结果，整条可重算链当场作废。
