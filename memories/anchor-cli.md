# anchor — 域的装配与命令行

`domains/coding/cli`。**里面没有一个 coding 相关的东西** ——
全部内容是四行装配（脚本传输 · git 内容提供方 · sqlite 后端）加一组通用动词。

装配就是域的决定：选哪个传输、哪个内容提供方、哪个后端。这三个选择一旦写死进基底，
那个壳就不再领域无关了，不管它代码里有没有出现域的词汇。

## 动词变了要问什么

`sync` 只开新锚，**绝不改判据** —— 改探针或改转换表是一次带密封理由的修订，走 revise。
让 sync 顺手改掉，等于让工具替作者做判断。

新增的动词如果能不带理由地改变一个锚的判据，那条线就破了。
