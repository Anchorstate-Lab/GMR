# Declared edges are criteria, so sync owns exactly its own share of them

A `links:` block in a note's frontmatter is the same species as `about:` — a
declaration living in the repository, reviewed in a commit, projected into
the store by `sync`. The store is the neutral half: an agent asserts the
same relation through the runtime with `SelfAttested`, a person with
`Adjudicated` through `gmr link`, and a vertical with no files at all
writes edges through the SDK and never meets this parser.

`align_links` reconciles only `Derived` rows. A declared edge missing from
the store is asserted; a `Derived` edge whose declaration is gone is
revoked; an identical edge someone else vouched for is invisible to the
diff, because the sets it compares are filtered by source before comparing.
Sync deleting an agent's assertion would be one layer overwriting another's
evidence — the [[three-layers]] failure wearing an edge costume.

`linked_target` is the whole grammar, and it refuses rather than guesses: a
bare name is the wikilink habit made runtime-real (`positioning` →
`git:memories/positioning.md`), a `provider:id` address reaches any
registered store, and anything else — a path, a `.md` suffix — errors with
the grammar in the message. A guessed address written into an append-only
store is this repository's own 381-row lesson; the wrong write is the one
you cannot take back.

Kinds are open vocabulary on purpose (no roster, nothing branches on them);
`doctor`'s census by kind and source is where fragmentation becomes visible
without being adjudicated.

## When this changes, ask

Does sync start touching rows whose source is not `Derived`, or asserting
with any other source? Either collapses the provenance axis this exists to
keep. Does `linked_target` start accepting paths or inferring providers?
That is guessing an address into a store that cannot forget one.
